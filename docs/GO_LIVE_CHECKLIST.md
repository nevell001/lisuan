# LiSuan 上线走查清单

> 用途：正式环境上线前的逐项验收清单。每项完成后在 `[ ]` 内打勾并记录执行人/日期。
> 当前代码门禁基线（`mvn -q clean verify`）：520 用例全绿，JaCoCo 行覆盖 ≥10%（现约 19.0%），SpotBugs High 0 缺陷。

## 0. 版本与产物

- [ ] 版本号四处同步一致：`AppConstants.APP_VERSION`、`pom.xml <version>`、`installer/Installer.java APP_VERSION`、`.env.example APP_VERSION`
- [ ] `mvn -q clean verify` 全绿（测试 + SpotBugs + JaCoCo 门槛）
- [ ] `mvn -DskipTests package` 产出可分发包（jar / exe / dmg / deb 按目标平台）
- [ ] Windows：`release.bat` 实机打包并启动验证（含 JDK/JRE 捆绑、路径含空格场景）
- [ ] macOS：dmg 安装、首次启动权限提示（网络/打印）验证

## 1. 数据库与配置

- [ ] MySQL 版本与字符集：utf8mb4 / utf8mb4_unicode_ci，时区 Asia/Shanghai
- [ ] `config/database.properties` 从 example 复制；**`db.password` 留空**（所有安装/配置通道都不会写入密码），密码由 `CASHIER_DB_PASSWORD` 提供：生产用环境变量/`.env`，`release.sh`/`release.bat` 会拒绝含非空 `db.password` 的配置文件
- [ ] `.env` 从 `.env.example` 复制：`MYSQL_ROOT_PASSWORD` 等真实密钥；`docker compose up -d mysql` 可启动
- [ ] 首次启动自动建表/升级（`DatabaseManager.initializeDatabase`）验证：全新库可启动、旧库升级无报错
- [ ] 数据库备份脚本验证：备份文件可生成、大小合理、无敏感密钥明文
- [ ] 数据库恢复演练：从备份恢复到空库，业务数据完整（商品/库存/交易/会员/设置）

## 2. 安全

- [ ] 默认账号 `admin/admin123` 已改强密码（BCrypt 存储），或上线脚本强制首次修改
- [ ] 弱口令/重复登录保护：`login_attempts` 锁定策略实测（连续失败锁定、成功重置）
- [ ] API 密钥：`TOKEN_SECRET` ≥32 字符随机值，`CORS_ALLOWED_ORIGINS` 收紧为实际终端地址
- [ ] 支付密钥（微信/支付宝）仅存在于生产配置，不入库不入 Git
- [ ] 审计日志：登录、交易、退款、审批、备份等关键操作有 `operation_logs` 记录并可查询
- [ ] 端口与网络：Javalin 8080 仅监听受信网段；多端同步 WebSocket 鉴权实测

## 3. 支付（真实通道）

- [ ] 微信 Native 支付：下单、二维码、支付成功回调验签、订单状态更新、超时取消
- [ ] 支付宝当面付：下单、回调、对账
- [ ] 银行卡（如有）：刷卡/插卡/挥卡、冲正、撤销
- [ ] 现金支付：部分支付（多次收款）、找零、退款联动库存/会员
- [ ] 回调幂等与防重放：重复回调、伪造回调、篡改金额均被拒绝（已有签名验证测试）
- [ ] 退款流程：原路退回、退款单状态同步

## 5. 核心业务走查（每项含 正常 + 异常 路径）

### 商品与库存
- [ ] 商品增删改、唯一名称校验、条码重复允许、成本/售价/库存初始化
- [ ] 商品导入（Excel）与模板、重复导入幂等
- [ ] 库存预警阈值、盘点（全盘/部分）、盘盈盘亏调整库存

### 销售与收银
- [ ] 购物车增删改、会员折扣、促销（满减/折扣）计算正确
- [ ] 挂单/取单、清空、快捷键（F1/F8/Ctrl+1/2/3 等）
- [ ] 交易流水、小票打印、库存扣减一致性（含并发压测：同商品并发结账）
- [ ] 交接班：开班/交班/结班金额核对、小票

### 采购与退货
- [ ] 采购单创建→审批→入库→库存/成本更新全链路
- [ ] 部分入库、超量拦截（入库数量 ≤ 采购数量）
- [ ] 退货：退货单创建→审批→库存回补/扣减、退款金额计算

### 会员与充值
- [ ] 会员开卡、余额充值、消费扣款、余额变动记录
- [ ] 余额并发安全（并发扣款不超扣）

### 报表
- [ ] 销售报表（按日/月/商品/收银员）、采购报表、库存报表、利润分析数据与人工核算一致
- [ ] 报表导出 Excel/PDF 打开正常、列宽/编码正确
- [ ] 大订单量下报表页加载有界（无全表拉取卡死）

### 系统
- [ ] 多语言切换（简中/繁中/英文）全页面生效，无缺 key
- [ ] 深色/浅色主题切换：列表、弹窗、日期选择器、提示框配色完整
- [ ] 备份与恢复：手动备份、自动备份周期、过期清理、恢复演练（见第 1 节）
- [ ] 系统设置（税率、币种、字号、收银偏好）持久化并在重启后保留
